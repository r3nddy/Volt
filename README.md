## ✨ Fitur

- 🔍 **Pencarian Kota** - Cari informasi cuaca berdasarkan nama kota
- 🌡️ **Suhu Real-time** - Menampilkan suhu terkini dengan akurat
- 💨 **Info Cuaca Lengkap** - Kelembaban, kecepatan angin, dan kondisi cuaca
- 🌅 **Ikon Cuaca Dinamis** - Tampilan ikon yang berubah sesuai kondisi cuaca
- 📱 **Responsif** - Tampilan optimal di desktop, tablet, dan mobile
- 🎨 **UI Modern** - Desain clean dan menarik dengan Tailwind CSS
